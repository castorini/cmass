Metrics

What each column measures

Acc.
Percentage of all questions answered correctly; unanswered questions count as failures. DSQA uses strict exact-set equality: every gold member and no incorrect additions, in any order.
P@all
Precision@all: the percentage of the distinct documents in a question's search results that are qrels, averaged over questions. Unjudged documents count as non-relevant, so it is a lower bound.
R@all
Recall@all: the percentage of a question's qrel documents that appear in any of its search results, each counted once, averaged over questions.
H.G.
Hop groundedness: the percentage of a question's hops supported by at least one retrieved document, averaged over questions. It uses hop-level judgments that are not released.
T.C.
Mean tool calls per question: searches plus document reads.
Closed-book
Accuracy from the question alone, with all tools disabled at the API level.

Setup

How the runs were made

Agent
Piika, which follows the agent design of Pi-Serini.
Tools
search returns at most five documents with previews of at most 500 characters; read_document returns the first 200 lines of a document.
Retriever
BM25 over ClimbMix through the Pyserini 2.4.0 REST backend (k1 = 0.9, b = 0.4).
Models
GPT-6.1 Sol with high reasoning effort; Gemma 4 31B IT and Qwen 3.5 9B with thinking enabled, served with vLLM.
Version
CMASS v1.0, released on 25 October 2026 as v2026.10.25. P@all, R@all and H.G. depend on the qrels, so report the version you used.
